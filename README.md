# 风羽 · 2D 格斗小游戏

Godot 4.7 制作的横版 1v1 格斗游戏，玩家对战 AI。

## 运行

1. 安装 [Godot 4.7](https://godotengine.org/download)
2. 打开 `project.godot`
3. 按 F5 运行

## 操作

| 按键 | 动作 |
|---|---|
| A / D | 左右移动 |
| W | 跳跃 |
| L | 冲刺（0.35 秒冷却） |
| J | 轻攻击（三段连招：4 / 4 / 6 伤害） |
| K | 重攻击（12 伤害，击退强） |
| U | 突进斩（消耗 30 气） |
| I | 手里剑（消耗 20 气，远程） |
| R | 回合结束后再来一局 |

## 内容

- `scenes/main.tscn` — 主场景，含血条、气条、99 秒倒计时和结算横幅
- `scenes/fighter.tscn` — 角色场景
- `scripts/fighter.gd` — 战斗核心：状态机（待机 / 移动 / 跳跃 / 冲刺 / 攻击 / 受击 / 死亡）、三段轻攻击连段、受击硬直与顿帧、击退、气条积累、AI 控制模式
- `scripts/main.gd` — 回合流程：倒计时、K.O. 判定、时间到比血量、按 R 重开
- `scripts/projectile.gd` — 飞行道具
- `scripts/hitfx.gd` — 命中特效
- `scripts/camera_shake.gd` — 镜头震动
